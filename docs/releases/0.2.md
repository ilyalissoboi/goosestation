GooseStation's first versioned release: everything since the fork from DuckStation (`a5bf1ba5cee7`, 2024-09-01, tagged
0.1). Builds for Windows (x64 and ARM64), Linux (AppImage and Flatpak), macOS (Universal) and, new, Android (arm64,
Android 10 or later). A PS1 or PS2 BIOS image from your own console is needed to play.

## Android

A new Android app of GooseStation's own, written for controllers first, with touch controls for phones and tablets:

- a library of covers or a list, sorted and searched as in Big Picture, multi-disc games as one tile, and cover
  downloads from sources you choose;
- your data folder anywhere on the device, shared with desktop (settings, memory cards, save states, covers);
- every desktop setting that works on Android, globally and per game, with controllers, hotkeys, macros and rumble;
- an in-game menu with save states (screenshots, shared slots, undo load), fast forward, disc changes and patch codes;
- RetroAchievements, hardcore included, and unlocks kept and sent later when you play offline;
- memory card sync and the memory card editor;
- post-processing shaders, slang presets included, and the texture cache with replacement packs;
- a signed APK that checks its channel for updates (`goosestation-android-arm64.apk`).

## Desktop and everywhere

- **Memory card sync**: memory cards synchronised save by save between your devices through S3-compatible storage,
  with a conflict screen when a save changed on two devices (Qt and Big Picture).
- **Memory card editor**: rename saves (title and file name); a game's save message shows its icon and title.
- **Slang shader presets** (RetroArch `.slangp`) as a stage of the post-processing chain on every renderer, with a
  shader browser, in-app downloads of the libretro, Retro Crisis, satpixie and lola-retro packs, favourites and saved
  chains.
- **Hardware texture cache** with per-texture replacement: published DuckStation packs for 4-bit and 8-bit textures
  load as published; dumping makes new packs. See `docs/texture-replacement.md`.
- **RetroAchievements without a connection**: unlocks and leaderboard entries are kept and sent, backdated, when the
  network is back; a game started offline runs in casual mode. The login token lives in `secrets.ini`, so
  `settings.ini` can be shared.
- **Game database**: new discs from redump.org's public PS1 list.
- **Big Picture**: text entry through the platform's keyboard (Steam's on a Steam Deck), and paste.
- **Updated platform**: SDL 3, Qt 6.12, and CJK fonts for Japanese, Korean and Chinese downloaded when needed.
- **Updates**: the Windows, macOS and AppImage builds update themselves from the Preview channel (Help > Check for
  Updates), and so does the Android app.

## Known limits

- The macOS app isn't notarized: the first time, right-click it and choose Open.
- GooseStation isn't registered with RetroAchievements yet, so hardcore mode may be refused for an unknown emulator.
- Discord rich presence is off until GooseStation has its own Discord application.
